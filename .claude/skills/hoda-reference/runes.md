# HoDA Runes — full reference

Runes = consumable/equippable modifiers. Two kinds appear in the data:

1. **Named battle runes** — timed buffs (retaliation, guard, stun-resist, etc.) with a buff type, value, and duration.
2. **Boost runes** — meta consumables (XP / Gold / Initiative / 'fastest'/'slowest' battle modifiers) that carry no localized name, only a buff type + value.

Sourced from `data/runes.json` (English). Icons local-only under `references/runes/` (`<Icon>.png`); buff-type icons live there too. EA/BioWare IP — reference only.

**122 runes total** — 82 named battle runes, 40 boost runes.
