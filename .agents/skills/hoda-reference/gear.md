# HoDA Gear (Equipment) — full reference

Gear = equippable items that grant **aura effects** (passive buffs to the wearer and/or allies, sometimes conditional on a target group/faction/speed). Sourced from hoda-base.xyz (`data/gear.json`, English text). Icons are local-only under `references/gears/` (`<Icon>_Portrait.png` = small in-slot icon, `<Icon>.png` = large art). EA/BioWare IP — reference only.

**266 gear items.** By rarity: Common 22, Uncommon 31, Rare 57, Epic 47, Legendary 59, Mythic 50.

Each gear's effects are written in HoDA's own aura vocabulary (e.g. *"+25% power to allies on ally death"*, *"Perceptive: Negates stealth"*, *"-25% slow resist"*). The **Restricts to** column lists category gates (a faction, group, specialty, or speed the wearer must match for the gear to apply / be equippable).
